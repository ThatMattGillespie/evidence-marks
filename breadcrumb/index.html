From one source back to all of them

After clicking chip 2 in an answer, the pane shows that one source. Today the only way back to the list of sources the chat cites is an unlabelled arrow in the head. Each version below makes that way back, or a way across to the next source, visible. Links are underlined; nothing here is final copy.

Things to weigh

  • A, B and C are the same idea at three strengths: the arrow you already have, given words. They cost nothing new to build and work for a Source opened from anywhere.
  • D and E add a way across, not only back: step to the next cited source without returning to the list. They only apply when the chat cites more than one source, and need a fallback when a source was opened from a search instead.
  • F puts the way back where a reader finishes, at the end of the source, and can sit with any of the others.
  • On a phone the pane is a drawer, so the same head carries over; B's breadcrumb would need to shorten to its last two steps.
  • In the Full entry, a breadcrumb gains a step: Sources cited / Source / Full entry.
